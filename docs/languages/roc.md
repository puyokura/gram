# Roc

[Roc](https://www.roc-lang.org/) は高速で親しみやすい関数型言語です。

Gram での Roc 言語サポートは、コミュニティが管理する
[Roc 拡張機能](https://github.com/h2000/zed-roc) によって提供されます。問題の報告先:
[https://github.com/h2000/zed-roc/issues](https://github.com/h2000/zed-roc/issues)

- Tree-sitter:
  [faldor20/tree-sitter-roc](https://github.com/faldor20/tree-sitter-roc)
- 言語サーバー:
  [roc-lang/roc/tree/main/crates/language_server](https://github.com/roc-lang/roc/tree/main/crates/language_server)

## セットアップ

1. Roc-Lang の Web サイトから [Roc のインストール](https://www.roc-lang.org/install) 手順に従います。
2. `roc` と `roc_language_server` が PATH に含まれていることを確認します。
