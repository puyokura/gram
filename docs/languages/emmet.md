# Emmet

Emmet のサポートは
[Emmet 拡張機能](https://github.com/zed-extensions/emmet) から利用できます。

[Emmet](https://emmet.io/) は Web 開発者向けのツールキットで、HTML と CSS の
ワークフローを大幅に改善できます。

- 言語サーバー:
  [olrtg/emmet-language-server](https://github.com/olrtg/emmet-language-server)
