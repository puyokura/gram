# Julia

Gram での Julia 言語サポートは、コミュニティが保守する
[Julia 拡張機能](https://github.com/JuliaEditorSupport/zed-julia) によって提供されます。
問題は
[https://github.com/JuliaEditorSupport/zed-julia/issues](https://github.com/JuliaEditorSupport/zed-julia/issues)
に報告してください。

- Tree-sitter:
  [tree-sitter/tree-sitter-julia](https://github.com/tree-sitter/tree-sitter-julia)
- 言語サーバー:
  [julia-vscode/LanguageServer.jl](https://github.com/julia-vscode/LanguageServer.jl)
