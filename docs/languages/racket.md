# Racket

[Racket 拡張機能](https://github.com/zed-extensions/racket) を通じて利用できます。

- Tree-sitter:
  [zed-industries/tree-sitter-racket](https://github.com/zed-industries/tree-sitter-racket)

は Gram ではまだサポートされていません。詳細については
[Issue #15789](https://github.com/zed-industries/zed/issues/15789) を参照してください。
