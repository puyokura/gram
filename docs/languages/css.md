# CSS

Gram は CSS をビルトインでサポートしています。

- Tree-sitter:
  [tree-sitter/tree-sitter-css](https://github.com/tree-sitter/tree-sitter-css)
- 言語サーバー:
  - [microsoft/vscode-css-languageservice](https://github.com/microsoft/vscode-css-languageservice)
  - [tailwindcss-language-server](https://github.com/tailwindlabs/tailwindcss-intellisense)

## Tailwind CSS

Gram は JavaScript、Astro、Svelte などの言語やフレームワーク向けに、
[Tailwind CSS](./tailwindcss.md) もそのまま利用できます。
