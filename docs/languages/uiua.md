# Uiua

[Uiua](https://www.uiua.org/) は、シンプルさ、美しさ、暗黙的なコードを重視した、汎用のスタックベースで配列指向のプログラミング言語です。

Uiua のサポートは、[Uiua 拡張機能](https://github.com/zed-extensions/uiua)を通じて利用できます。

- Tree-sitter:
  [shnarazk/tree-sitter-uiua](https://github.com/shnarazk/tree-sitter-uiua)
- 言語サーバー: [uiua-lang/uiua](https://github.com/uiua-lang/uiua/)
